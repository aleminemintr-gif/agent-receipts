### 2. Concordium Trusted Agents Hackathon (Encode Club) — deadline 2026-12-09, 23:59 UTC
- Six-week online hackathon (Nov 2 – Dec 9, 2026). Theme is agent accountability: verified-human badges, ERC-8004 Agent Card registry entries, and x402 agent-to-agent payments via a hosted MCP server and A2A. Explicitly welcomes EVM and Solana builders; "bring an agent you already run".
- No cash prizes announced; winners can pitch directly to Concordium's 75M CCD grants committee (subject to its terms).
- Fit: our receipts are exactly "make an agent accountable" evidence. Submission needs a description, public repo, <=3 min demo video, CCDExplorer link and a go-live plan.
- Sources: https://hack123.henryht.sh/en/h/concordium-trusted-agents-hackathon-2026 and https://www.encodeclub.com/programmes/concordium-trusted-agents-hackathon
- Needs: free Encode Club account (owner).

- Source: same Celo DevRel post: https://celo-devs.beehiiv.com/p/agents-open-for-business
